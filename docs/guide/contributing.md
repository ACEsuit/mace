# Contributing and repository agents

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for setup, PR checks and the examples
requirement, and [GOVERNANCE.md](../../GOVERNANCE.md) for decision ownership and
release policy. Committee appointments remain an explicit human decision.

The root [CLAUDE.md](../../CLAUDE.md), per-package guidance and tracked
[skills.json](../../skills.json) describe the native workspace. Install skills
from this local checkout with `npx skills add .`; the published repository's
available skills depend on which branch has been merged. No private tool or
private filesystem path is required to read these instructions.
